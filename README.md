# 🏃‍♂️ 3D Subway Surfers Blockout (Lab 03) 🎮

Welcome! 👋 This is my **Lab 03 Game Development Project**. 

In this project, I created a **3-lane level blockout** inspired by *Subway Surfers*! 🛹✨

---

## 🟩 What is Blockout?

Blockout means designing a level using basic 3D shapes (like cubes and blocks). This helps test the **game mechanics** and **player movement** before adding final graphics!

---

## 🌟 Key Features of This Blockout

- 🛣️ **3-Lane Layout:** Built Left, Center, and Right lanes using basic block structures.
- 🎯 **Core Mechanics First:** Designed to test smooth movement, lane switching, and jumping.
- 🧱 **Simple Environment:** Uses placeholder blocks and obstacles for a clean, distraction-free layout.
- 🪙 **Collectibles Layout:** Placed coins and basic hazard placeholders across all three lanes.
